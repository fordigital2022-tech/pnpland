# ПНП — Первая наркологическая помощь

Адаптивный макет страницы «Нарколог на дом» по `PNP-Codex-kit.zip`. Статический HTML/CSS/JavaScript без фреймворков, сторонних шрифтов, аналитики, коллтрекинга и производственных зависимостей. Сборка не публикует сайт.

## Запуск

Нужен Python 3.9+. Node.js нужен только для npm-команд и браузерного теста.

```bash
cd /workspace/pnpland
npm run dev
```

Сервер слушает порт 3000. Прямой эквивалент: `python3 -m http.server 3000 --bind 0.0.0.0`. Остановить: Ctrl+C. Используйте существующий checkout; отдельный Git worktree не нужен. Зависимости приложения устанавливать не требуется.

```bash
npm run build
npm run preview
```

`build` создаёт самостоятельную папку `dist/`. Команда `preview` запускается после остановки dev-сервера. Папки docs, scripts и исходный HTML клиники в сборку не входят. Данные загружаются по HTTP: открытие index.html через file:// не поддерживается.

## Редактирование

- `data/config.json`: единые контакты, юридические ссылки, флаги `needsConfirmation`, настройки адаптера формы и отключённой акции.
- `data/content.json`: весь исходный текст в 19 пронумерованных блоках; секции услуг, тарифов, безопасного формата, результатов, FAQ и документов рендерятся из этих данных. Номер и Markdown-заголовки блоков используются как ключи: при изменении структуры обновляйте соответствующий разбор в app.js.
- `data/view.json`: текст хиро, направления помощи, преимущества, статистика и описания консультаций для специальных компоновок.
- `data/specialist.json`: все 8 специалистов с локальными фотографиями и отметками подтверждения.
- `data/reviews.json`: 21 исходная запись и 5 рейтингов; интерфейс показывает 20 уникальных отзывов, убирая точный повтор Ангелины.
- `app.js`: компоненты, служебные подписи, навигация и интерактивность. `style.css`: оформление и адаптивность.
- `docs/TASK.md`, `docs/CONTENT-SOURCE.md`, `docs/source/`: оригинальное задание и полный снимок источника. Это справочные материалы, оригинальные скрипты сайта не исполняются на лендинге.

В `data/content.json` сохраняется исходная формулировка бренда; замена на ПНП делается только в редакционном блоке о подходе. Цитаты, ФИО и юридическое лицо не переименованы. Полные составы тарифов сохранены отдельно. Неподтверждённые сведения имеют флаги в config.json и видимые подписи в макете. Флаги не означают юридическую или медицинскую проверку. Перед выпуском владелец должен подтвердить контакты, цены, команду, отзывы, рейтинги, фотографии, статистику, лицензию и утверждения о клинике, затем внести согласованные данные. Акция исходника не действует автоматически: исходные desktop/mobile-изображения сохранены в конфигурации, в интерфейсе отдельный адаптированный слот без неподтверждённых условий.

## Формы и телефоны

По умолчанию `form.mode = "demo"`, `endpoint = null`. Поля, маска, валидация и обязательное согласие работают, но персональные данные никуда не отправляются. Сообщение явно сообщает, что заявки нет.

Для подключения согласованного обработчика задайте `form.mode = "live"` и same-origin `endpoint`, например `/api/callback`. Сервер должен принимать POST JSON `{name, phone, consent}`, проверять входные данные и возвращать HTTP 2xx с JSON `{"success": true}` только после подтверждённой доставки. Любой иной результат показывает ошибку. Самого сервера приёма заявок в этом макете нет; Python dev-сервер POST не обслуживает. Нужны согласованный backend, актуальная политика обработки данных и защита обработчика на сервере.

Все телефонные ссылки берутся из единого config. При согласованном подключении коллтрекинга используйте `window.pnp.updatePhone('+79990001122', '+7 (999) 000-11-22')`: меняются и текстовые номера, и все tel-ссылки. Сам коллтрекинг не подключён.

## Проверка

```bash
npm run build
npm test
```

Браузерный тест использует Playwright, предустановленный в текущей облачной среде, и `/usr/bin/chromium`. Для другой машины установите Playwright в своё окружение и при необходимости задайте `PLAYWRIGHT_MODULE` (путь к модулю) и `CHROMIUM_PATH` (исполняемый файл браузера). Тест сам запускает временный сервер сборки на порту 3177 и останавливает его.

Проверяются порядок секций, 5 услуг, 3 тарифа со всеми 8/10/10 пунктами, 8 врачей, 20 уникальных отзывов, 5 площадок, 8 FAQ, изображения, ширины 320/375/768/1440/1920, отсутствие внешних запросов, клавиатурное управление, модальные окна и фокус, документы, формы и единый телефон. Успех, ошибка и загрузка обработчика проверяются имитацией ответа сервера, без внешней отправки. Отчёт: `docs/VALIDATION.md`.

## Фирменный стиль ПНП

Название: **ПНП — Первая наркологическая помощь**.

Файлы логотипа: `assets/brand/pnp-logo-transparent.png` — рабочий прозрачный логотип; `assets/brand/logo-reference.png` — референс композиции и инверсии; `assets/brand/ui-reference.png` — ориентир интерфейса. Последний не вставляется вместо HTML.


| Роль | HEX | Применение |
|---|---|---|
| Графит | #28332F | Заголовки, основной текст, логотип |
| Хвойный | #386451 | Основные CTA, акценты, тёмные секции |
| Молочный | #F7F6F2 | Основной фон |
| Шалфей | #E8EEE7 | Подложки и мягкие выделения |
| Белый | #FFFFFF | Карточки, формы, текст на зелёном |
| Серый | #68716B | Вторичный текст |

Технические оттенки: граница #D8DFD8, hover кнопки #2D5142. Цвета не заменять приблизительными аналогами. Бирюзовый, индиго, фиолетовый, коралловый и золотой из прежних материалов не использовать.

Шрифт: Manrope, кириллица, веса 400, 500, 600, 700. Заголовки 600, основной текст 400, кнопки 600. H1 56/62 px на десктопе и 34/39 px на мобильном. H2 40/46 и 28/34 px. Текст 18/28 и 16/25 px. Локальные файлы шрифта предпочтительны, при отсутствии используй системный sans-serif до подключения.

Контентная ширина 1200 px. Поля 32 px на десктопе, 20 px на мобильном. Межсекционные отступы 88 и 56 px. Скругления карточек 14 px, кнопок и полей 12 px. Карточки с тонкой границей, почти без теней. Иконки линейные, stroke 1.8–2, одинаковый размер 24 или 32 px. В логотип медицинский крест не добавлять.

Основная кнопка: хвойный фон и белая подпись. Вторичная: прозрачный фон, хвойная рамка и текст. Минимальная высота 48 px. На тёмном фоне вторичная кнопка с белой рамкой. Никаких градиентов на кнопках. Видимый focus, корректные hover/disabled/loading.

Логотип сохранять без перерисовки и искажения. На тёмном фоне допустима полностью белая версия через CSS `filter: brightness(0) invert(1)`. Подпись не растягивать отдельно от знака. Не заменять логотип обычным текстом ПНП.

Фото: естественный дневной свет, нейтральная или тёплая цветопередача, спокойный профессиональный вид врачей. Без декоративной зелени, изображения алкоголя и драматизации. Чередовать молочные и белые секции, шалфей использовать локально. Поддержку семьи и финальный CTA можно выделить хвойным фоном.
